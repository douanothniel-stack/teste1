# Portfolio Douan Samuel

Ouvre `index.html` dans un navigateur (le formulaire demande un serveur PHP).

## À personnaliser
- `index.html` : remplace les passages marqués [À COMPLÉTER] (bio, citation, e-mail) et ajuste services et compétences.
- `contact.php` : remplace `ton-email@exemple.com` par l'adresse qui doit recevoir les messages.
- `assets/` : photo.jpg (accueil), photo2.jpg (à propos), studio.jpg, exterieur.jpg, noirblanc.jpg (galerie).
- `fx.js` : texte de l'écran d'ouverture (LOADER_TEXT).
